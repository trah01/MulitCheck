# mulitcheck

mulitcheck 是一个 Chrome 插件，用于在网页中通过 `Shift + 点击` 批量勾选或取消复选框。

## 功能

- 普通点击复选框会记录当前锚点。
- 按住 `Shift` 再点击另一个复选框，会批量切换两个复选框之间的范围。
- 范围会在最近的共同父级容器内计算，兼容常见的 `label` / `div` 包裹结构。
- 批量结果跟随目标复选框的最终状态：
  - 目标被勾选，则范围内复选框被勾选。
  - 目标被取消，则范围内复选框被取消。
- 自动跳过禁用状态的复选框。
- 支持全局开关和当前网站单独覆盖设置。
- 支持中文和英文，可跟随浏览器语言，也可以手动选择。

## 权限说明

- `storage`：保存全局开关、网站覆盖设置和语言偏好。
- `activeTab`：用户打开插件弹窗时，临时读取当前标签页 URL，用于识别当前网站主机名。
- 内容脚本运行在 `http://*/*`、`https://*/*` 和用户授权后的 `file://` 本地页面，用于监听复选框点击并执行范围选择。

插件不会读取表单内容、密码、支付信息、Cookie、文件，也不会上传数据到外部服务器。

## 本地安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。

### 本地文件页面

如需在直接打开的本地 HTML 文件上使用：

1. 打开 `chrome://extensions/`。
2. 找到 mulitcheck，进入“详情”。
3. 开启“允许访问文件网址”。
4. 刷新本地页面。

如果用本地 HTTP 服务访问，例如 `http://localhost:4173/test-page.html`，不需要开启文件网址权限。

### Google 发布/商店页面

Chrome 会限制扩展在部分浏览器内置页面、Chrome Web Store 或扩展发布后台页面上运行内容脚本。即使 manifest 匹配了 `https://*/*`，这些页面也可能不会注入脚本；这是 Chrome 的安全限制，不是插件开关失效。

## 使用方法

1. 在网页中先普通点击一个复选框。
2. 按住 `Shift`，点击同组里的另一个复选框。
3. 打开插件弹窗，可以设置：
   - 全局启用 / 停用。
   - 当前网站跟随全局、强制开启或强制关闭。
   - 自动语言、简体中文或英文。

网站级设置优先级高于全局开关。
